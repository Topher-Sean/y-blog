## 项目介绍

- GEO 搜索与智能行业报告平台是面向品牌分析、行业研究和舆情洞察的 AI 搜索与报告平台，提供智能搜索、行业广场、品牌报告、行业报告、报告阅读、竞品分析、舆情分析、报告分享和会员购买等能力。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia / 状态管理
- ECharts
- 国际化
- 流式接口
- PDF 导出

## 核心工作

### 1. 核心页面开发

- 负责首页、搜索页面、搜索结果、行业广场、品牌报告、行业报告、报告详情和个人中心等页面。
- 开发会员权益、购买页面、订单状态、支付结果和用户账户等业务流程。
- 根据不同报告类型组织页面路由和内容结构，支持品牌、行业、竞品和舆情等多种报告场景。
- 实现桌面端、移动端和不同屏幕尺寸下的响应式布局。

### 2. 报告阅读器

- 负责报告阅读页面的模块化设计和页面结构拆分。
- 支持报告标题、摘要、行业概览、平台分析、行业洞察、竞品分析、舆情内容、引用来源和行动建议等内容区块。
- 根据报告类型和数据状态动态展示不同模块，处理模块缺失、数据为空和接口异常等情况。
- 实现目录导航、锚点跳转、分段阅读、顶部返回、滚动定位和报告分享等交互。
- 参与报告内容的多版本兼容和后端数据结构转换。

### 3. AI 报告生成流程

- 接入 AI 报告生成接口，处理生成任务创建、生成进度、分段响应和最终结果展示。
- 设计生成中、生成成功、生成失败、重新生成和中断恢复等状态。
- 统一处理长时间请求过程中的进度反馈和用户操作限制。
- 针对接口异常、网络中断、数据缺失和重复提交等情况增加前端保护逻辑。
- 将生成数据转换为适合页面展示的报告结构，降低页面组件对后端数据细节的依赖。

### 4. 可视化与数据展示

- 使用 ECharts 等图表组件展示行业数据、趋势分析、竞品对比和舆情数据。
- 处理图表容器尺寸变化、数据为空、数据异常和移动端展示问题。
- 根据报告主题和业务类型组织图表样式、图例、坐标轴和数据说明。
- 支持报告内容中的引用来源、数据说明和相关跳转。

### 5. 公共能力建设

- 抽象 HTTP 请求、请求拦截、统一错误处理、鉴权缓存和接口状态管理。
- 建立报告类型、报告版本、报告模块和报告路由等公共类型定义。
- 维护国际化资源，按业务域拆分首页、报告、会员、搜索、分享和公共文案。
- 封装报告分享、公开访问、PDF 导出、锚点导航和页面跳转等公共工具。
- 通过功能开关控制部分实验性功能和不同产品版本的展示逻辑。

## 项目亮点

- 将不同报告产品归并为统一的报告展示框架，减少同类页面重复开发。
- 通过模块化报告结构支持不同业务线快速扩展新的报告类型。
- 对 AI 生成状态进行统一管理，改善长时间生成过程中的用户反馈。
- 覆盖多语言、多区域和 PC / 移动端场景，具备较强的产品扩展能力。
