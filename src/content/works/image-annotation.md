## 项目介绍

- 图像标注平台是公司内部智能数据标注系统，面向 OCR、版式分析与结构化标注任务，覆盖数据看板、任务创建、标注编辑、结果核验与数据导出等核心流程。

## 项目说明

- 项目类型：内部业务系统
- 核心场景：OCR 文本识别、版式分析、智能预标注、结果核验

## 技术栈

- Vue3
- TypeScript
- Pinia
- Vue Router
- OCR 接入

## 核心工作

- 负责公司内部智能数据标注平台前端开发，基于 Vue3 + TypeScript + Pinia + Vue Router 搭建业务系统，完成数据看板、任务创建、标注编辑、结果核验、数据导出等核心模块建设。
- 主导标注工作台核心功能实现，设计并开发画布标注交互系统，支持页面分类、目标框选、元素分组、多面板联动编辑等能力，提升复杂标注场景下的操作效率与可用性。
- 接入 OCR 文本识别与版式分析能力，支持自动识别标注区域文本、智能预标注页面元素信息，减少人工录入成本，提升整体标注效率和任务处理质量。
- 封装统一前端请求层，完成鉴权、异常处理、文件上传下载、JSON / FormData 多类型接口适配，增强前后端联调效率，提升系统可维护性与扩展性。
