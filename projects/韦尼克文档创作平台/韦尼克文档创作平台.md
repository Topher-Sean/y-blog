## 项目介绍

- 韦尼克文档创作平台是面向企业客户的 AI SaaS 平台，围绕应用创建、能力接入、在线调试、账户支付、工单支持与数据分析构建完整业务闭环。

## 项目地址

- 访问地址：<https://b.yoo-ai.com/>

## 技术栈

- React
- React Router
- Arco Design
- SCSS
- ECharts
- D3

## 核心工作

- 参与韦尼克智能创作平台前端开发，负责 AI SaaS 平台核心业务模块建设，涵盖应用创建、能力接入、在线调试、账户与支付管理、工单支持等业务场景。
- 基于 React、React Router、Arco Design、SCSS 搭建中后台系统页面与通用组件，完成多模块控制台的页面开发与交互实现，提升平台功能扩展性与页面复用性。
- 封装统一接口请求层与前端环境配置，接入应用管理、资源包、订单、发票、认证、工单等多个业务接口，保障前后端联调效率与接口调用稳定性。
- 负责接口调试平台功能开发，支持根据接口元数据动态生成调试表单、参数配置、请求头展示与响应结果查看，提升内部测试与交付效率。
- 参与平台数据看板与运营分析模块建设，结合 ECharts / D3 实现调用趋势、资源消耗、账户信息等数据可视化展示，增强平台运营支撑能力。
- 参与会员体系、子用户管理、余额预警、月结等企业级功能建设，具备较强的复杂业务理解能力、跨模块协作能力和中后台项目落地能力。
