## 项目介绍

- ChatPPT 编辑器是一套面向在线演示文稿生产、编辑与交付的多端前端系统，覆盖文档编辑、导入解析、导出分享、AI 路演等核心业务场景。

## 项目地址

- 官网地址：<https://chatppt.cn/>

## 技术栈

- Vue3
- TypeScript
- Vite
- Pinia
- Canvas / HTML5
- IndexedDB
- WebSocket

## 核心工作

- 负责在线 PPT / 演示文稿编辑平台前端核心功能研发，基于 Vue3 + TypeScript + Vite + Pinia 搭建复杂编辑器应用。
- 主导多视图编辑能力建设，完成画布编辑、缩略图编排、脑图视图、溯源视图等模块设计与实现，提升复杂演示内容的组织效率和可视化表达能力。
- 实现富文本、图片、图表、表格、音视频、LaTeX、词云、3D 组件等多类型元素的统一渲染与编辑，沉淀可扩展的组件化方案，增强系统可维护性与扩展能力。
- 负责文档导入导出链路开发，支持 PPT / PDF / JSON 等内容导入解析，以及 PPTX、PDF、图片、HTML、JSON 等多格式导出，打通演示文稿从生产、编辑到交付的完整流程。
- 推动 AI 能力落地，接入 AI 辅写、翻译、美化、路演稿生成、配音等功能，将智能生成能力融入编辑工作流，提升内容生产效率与产品差异化竞争力。
- 设计并实现基于 IndexedDB 的本地快照机制与撤销 / 重做能力，结合 WebSocket 增量同步方案，提升复杂编辑场景下的数据可靠性、交互流畅度和协同体验。
- 负责分享路演、播放统计、互动数据分析等业务模块开发，支撑文档传播、效果追踪和业务复盘。
- 项目同时兼容插件端、小程序端、App 端、H5 端。
